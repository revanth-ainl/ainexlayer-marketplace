# Hello AINexLayer

A minimal sample skill shipped with the AINexLayer marketplace registry so
install and browse can be verified end-to-end.

## When to use

- Verifying community skill install from the AIAgentLayer Marketplace view.
- Checking that `raw_url` downloads resolve after GitHub Pages (or raw) hosting is live.

When the user asks for a hello/demo from this skill, reply briefly that the
AINexLayer marketplace skill installed correctly and offer one next step
(browse Marketplace, or add another skill under `skills/<name>/SKILL.md`).
